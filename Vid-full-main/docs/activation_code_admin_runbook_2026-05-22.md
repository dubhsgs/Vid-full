# VAID Activation Code Admin Runbook

Date: 2026-05-22

## Purpose

This document explains how to manually generate VAID activation codes in Supabase.

Activation codes are stored in:

```sql
public.license_keys
```

Users redeem activation codes on the VAID website. After redemption, credits are added to the user's account.

## Code format

Activation codes are generated by the database function:

```sql
public.generate_license_key_code()
```

The generated format is:

```text
VAID-XXXX-XXXX-XXXX
```

Do not manually invent codes. Always use the database function to avoid duplicate or invalid codes.

## Generate a 1-credit activation code

Run this in Supabase SQL Editor:

```sql
insert into public.license_keys (
  key,
  pack_size,
  total_uses,
  remaining_uses,
  status,
  used
)
values (
  public.generate_license_key_code(),
  1,
  1,
  1,
  'active',
  false
)
returning key, pack_size, remaining_uses, status;
```

## Important behavior

- One activation code can be redeemed by only one user account.
- If the code is for 5 credits, the user receives all 5 credits when redeeming it.
- After redemption, the code becomes exhausted and cannot be reused.
- Keep generated codes private. Anyone who has a valid unused code can redeem it.

## Check a code

```sql
select
  key,
  pack_size,
  total_uses,
  remaining_uses,
  status,
  redeemed_by_user_id,
  redeemed_at,
  created_at
from public.license_keys
where key = 'VAID-XXXX-XXXX-XXXX';
```

## Disable an unused code

```sql
update public.license_keys
set status = 'revoked'
where key = 'VAID-XXXX-XXXX-XXXX'
  and status = 'active'
  and remaining_uses > 0
  and redeemed_by_user_id is null;
```
